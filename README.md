# Personal Website

Website personal branding milik **Iras Alizubeer**. 

## Tentang Website
Website personal branding siswa IT yang tertarik pada pengembangan web dan teknologi terbaru di bidang software development.

## Fitur
- Hero section dengan nama dan tagline
- About me
- Daftar skill
- Section project (placeholder)
- Contact dan social media (Instagram dan WhatsApp)
- Desain responsif dan dark mode
- Dibangun dengan framework JavaScript modern dan Tailwind CSS

## Teknologi yang Digunakan
- JavaScript
- React / Next.js
- Tailwind CSS

## Cara Menjalankan Project
1. Clone repository ini
2. Install dependency
-npm install
3. Jalankan server development
-npm run dev
4. Buka browser dan akses `http://localhost:8080`
